# Английские слова — локальный тренажёр

Аналог Quizlet, который работает прямо из этой папки: без интернета, без сервера,
без установки. Слова показываются с русской транскрипцией и ударением:
**access (э́ксес)**, **hypothesis (хайпо́сэсис)**.

Каждая партия слов — **отдельный модуль** со своим собственным прогрессом,
который тренируется независимо от остальных.

## Как запустить

Дважды кликнуть по **`index.html`** — откроется в браузере. Всё.

Совет: перетащи вкладку в закладки, чтобы открывать в один клик.

## Что лежит в словаре

200 академических слов из списка TOEFL, разложенных по уровню сложности:

| Модуль | Слов |
|---|---|
| TOEFL · Лёгкие слова | 50 |
| TOEFL · Частые слова | 50 |
| TOEFL · Средние слова | 50 |
| TOEFL · Сложные слова | 50 |

У каждого слова есть перевод, русская транскрипция, короткое определение
по-английски (как в словарях для экзамена) и пример с переводом.

## Модули

Каждая загруженная партия слов живёт отдельным модулем. Модуль выбирается
плиткой на главном экране, и дальше **всё** — карточки, тест, заучивание,
пары, список слов — работает только с его словами.

У каждого модуля свои:

* прогресс по каждому слову (новое / учу / выучено) и общий процент;
* незаконченный раунд заучивания — он ждёт возвращения именно в этом модуле;
* рекорд в «Подборе пар»;
* сброс прогресса (⚙ Настройки → нужный модуль → «Сбросить»).

Одно и то же слово в разных модулях учится независимо: выучил `access` в одном —
в другом оно останется новым.

Плитка **«Все модули»** тренирует всё сразу; прогресс при этом по-прежнему
считается для каждого модуля свой.

## Режимы

| Режим | Что делает |
|---|---|
| **Заучивание** | Главный режим. Раунды по 7 слов, каждое слово проходит три ступени: выбор перевода → выбор английского слова → написать самому. Ошибся — слово падает на ступень назад и возвращается в этот же раунд. Незаконченный раунд восстанавливается после закрытия браузера. |
| **Карточки** | Классические карточки: клик или пробел — перевернуть, «знаю / не знаю». Отметки и место в колоде сохраняются. Переключается, что показывать спереди — английское или русское. |
| **Тест** | Выбор из четырёх вариантов в обе стороны, 10/20/50/все слова. В конце — список ошибок и кнопка «повторить ошибки». |
| **Ввод с клавиатуры** | Написать английское слово по русскому переводу. |
| **Подбор пар** | Собрать 6 пар на скорость, с таймером и рекордом. |
| **Формы глагола** | `-s`, `-ing`, Past Simple и третья форма. Появляется, если в модуле есть глаголы. |
| **Список слов** | Все слова, поиск (по слову, переводу и транскрипции), озвучка, отметка ⭐ «сложное». |
| **Чтение** | 30 коротких текстов A1–B1 с переводом слов и предложений по наведению. **Не зависит от модулей со словами.** |

После каждого ответа — верного или неверного — открывается разбор: слово,
транскрипция, перевод, множественное число и ступень заучивания. Разбор
**не исчезает сам**, следующий вопрос появляется по кнопке «Дальше» или `Enter`.

Полоса наверху показывает движение по текущему раунду (`3 / 7`) — она сдвигается
после каждого верного ответа. Общий счётчик «выучено N из M» растёт медленнее:
слово попадает в выученные, только пройдя все три ступени.

Наверху главного экрана выбирается модуль, а под ним — **что тренировать**:
все слова, только новые, невыученные, сложные (те, где были ошибки) или
отмеченные звёздочкой.

### Горячие клавиши

| Клавиша | Действие |
|---|---|
| `1`–`4` | выбрать вариант ответа |
| `Enter` | проверить ответ / следующий вопрос |
| `Пробел` | перевернуть карточку |
| `←` `→` | предыдущая / следующая карточка |
| `↑` `↓` | на карточке: «знаю» / «не знаю» |
| `S` | озвучить слово на карточке |
| `Esc` | вернуться на главный экран |

## Карточки

Отметки **«знаю / не знаю» сохраняются** — отдельно для каждого модуля.
Вернувшись, видишь то же, что оставила: колода в том же порядке, карточка
та же, на которой остановилась, точки внизу — зелёные у известных слов
и красные у незнакомых. Под точками стоит счёт «знаю · не знаю · без отметки»
и ссылка **«очистить отметки»**, если хочется начать разбор заново.

«Перемешать» и «Пройти заново» меняют порядок, но отметки не трогают.
Сброс прогресса модуля в ⚙ Настройках очищает и их тоже.

## Формы глагола

Отдельный режим для **всех глаголов** текущего модуля, с двумя вкладками.

### Вкладка «Формы»

На каждый глагол — четыре строки, в которые нужно вписать форму:

| Строка | Время | Пример |
|---|---|---|
| `he / she / it` | Present Simple | She **achieves** her goals. |
| `-ing` | Present Continuous | She is **achieving** her goals. |
| Past Simple | Past Simple | She **achieved** her goals. |
| Participle | Present Perfect | She has **achieved** her goals. |

* Предложение берётся из поля `ex` у слова, так что форма сразу стоит
  в живом контексте, а не отдельным словом.
* Рядом — сворачиваемая подсказка **«? правило»**: какое правило работает
  в этой строке. Например, что после `-s, -ss, -sh, -ch, -x, -o` пишется `-es`
  (`access → accesses`), что согласная + `y` даёт `-ies` (`rely → relies`),
  что немая `-e` выпадает перед `-ing` (`achieve → achieving`) и что ударный
  слог «согласная + гласная + согласная» удваивает букву (`commit → committing`).
  Открытые подсказки не закрываются при проверке.
* У неправильного глагола в шапке стоит пометка вида **неправильный: sought,
  sought**, а правило честно говорит, что форму нужно запомнить целиком.
* У глаголов-состояний (`consist`, `require`, `involve` и других с пометкой
  `noIng`) строки `-ing` просто нет: «is consisting» по-английски не говорят.
* Наверху — счётчик верных ответов и кнопки **«Проверить всё»**,
  **«Показать ответы»**, **«Сбросить»**.
* Строка проверяется сама, как только уйдёшь из поля, или по `Enter` —
  `Enter` заодно перескакивает к следующей строке.
* **Ответы сохраняются.** Закрыл вкладку, выключил компьютер, вернулся через
  неделю — видно, что уже отработано: верные строки остаются зелёными вместе
  с тем, что ты написала, ошибки — красными и открытыми для правки. В шапке
  каждого глагола стоит счётчик вида **3 / 4**, а когда сделано всё — он
  становится зелёным. Отдельно для каждой вкладки и каждого модуля.
* «Сбросить» очищает только текущую вкладку; сброс прогресса модуля
  в ⚙ Настройках очищает и эти упражнения тоже.

### Вкладка «Перевод предложений»

Те же предложения, но целиком и с русского на английский:

| Задание | Время | Ответ |
|---|---|---|
| Она достигает своих целей шаг за шагом. | Present Simple | `She achieves her goals step by step.` |
| Она достигает своих целей шаг за шагом. | Present Continuous | `She is achieving her goals step by step.` |
| Она достигала своих целей шаг за шагом. | Past Simple | `She achieved her goals step by step.` |
| Она достигала своих целей шаг за шагом. | Present Perfect | `She has achieved her goals step by step.` |

Русское «сделала» — это и Past Simple, и Present Perfect, поэтому **время
указано рядом с заданием** отдельной плашкой: догадываться не нужно.

* Регистр и точка в конце не важны: `she achieves her goals step by step`
  засчитывается. Буквы — важны.
* У каждой строки есть сворачиваемая **«? подсказка»**: правильное предложение
  целиком, кнопка **🔊 послушать** и то же правило, что во вкладке «Формы».
* Счётчик, «Проверить всё», «Показать ответы» и «Сбросить» работают отдельно
  для каждой вкладки, а ответы при переключении не пропадают и переживают
  перезагрузку страницы.

Чтобы глагол попал в этот режим, у него должно быть `pos: "глаг."`.
Поля, из которых собираются задания:

```js
{ en: "achieve", tr: "эчи́в", ru: "достигать, добиваться", pos: "глаг.",
  ex: "She achieves her goals step by step.",        // Present Simple, 3-е лицо
  exRu: "Она достигает своих целей шаг за шагом.",   // его перевод
  exRuPast: "Она достигала своих целей шаг за шагом.",
  forms: "sought, sought",   // только у неправильного глагола
  noIng: true,               // только у глагола-состояния
  conj: { past: "spent" } }  // если нужно перекрыть одну форму
```

`ex` обязательно стоит в **Present Simple, 3-е лицо единственного числа**:
приложение находит в нём форму на `-s` и из неё строит остальные времена.
Поэтому «He accesses the library.», а не «They access the library.».

## Чтение

Отдельный раздел с короткими текстами. Он **никак не связан с модулями слов**:
свои тексты, свой словарь подсказок, своя отметка «прочитано». Сейчас там
30 текстов уровней **A1, A2 и B1** на 16 тем — день, семья, еда, город, работа,
наука, деньги, путешествия и другие.

Как читать:

* **Наведи на слово** — всплывает перевод. Если форма не словарная, начальная
  форма стоит в скобках: `authorities — власти (authority)`.
* **Нажми на слово** — оно произносится вслух.
* **Наведи на точку в конце предложения** (она подсвечена) — перевод всего
  предложения и кнопка **🔊 послушать**. Нажатие на саму точку тоже читает
  предложение целиком.
* **Повторное нажатие останавливает чтение** — и для слова, и для предложения,
  и для всего текста. Кнопка «Слушать текст» при этом превращается
  в «⏹ Остановить».
* В подсказке к слову есть кнопка **«＋ в словарь»** — она складывает слово
  в модуль для изучения (см. ниже).
* Кнопка **«Слушать текст»** читает весь текст, **«Отметить прочитанным»** —
  ставит галочку в списке. Стрелки внизу листают тексты подряд.

### Слово из текста — в модуль

Нажми **«＋ в словарь»** в подсказке. Откроется окно с уже заполненной
заготовкой карточки:

* **английское слово** — приложение подставляет начальную форму из скобок,
  а не ту, что в тексте: `authorities` → `authority`;
* **транскрипция** — считается автоматически по тем же правилам, что
  в конвертере PDF. Это черновик: английское чтение по написанию угадывается
  плохо, а ударение ставится на первый гласный — обязательно проверь.
  Под полем есть кнопки гласных с ударением;
* **перевод** и **часть речи** — тоже заготовка, всё можно поправить;
* **модуль** — существующий «свой» модуль или новый (по умолчанию
  «Слова из текстов»).

Такой модуль **хранится в браузере**, а не в `words.js`, и сразу доступен во
всех тренировках со своим отдельным прогрессом. На главном экране и в
настройках он помечен значком «в браузере».

Чтобы сохранить его насовсем: ⚙ Настройки → нужный модуль → **«Выгрузить в
words.js»** → скопировать блок и вставить в файл. `id` при этом сохраняется,
поэтому прогресс не потеряется, а модуль из браузера можно будет удалить.

Пополнять «свой» модуль можно и через экран **«＋ Добавить слова»** — если
выбрать его как цель, слова добавятся сразу, без возни с кодом.

Тексты фильтруются по уровню и по теме.

### Как добавить свой текст

Тексты лежат в `texts.js` отдельно от слов:

```js
{ id: "t31", level: "B1", topic: "Работа",
  title: "A New Job", titleRu: "Новая работа",
  s: [
    ["She started a new job in May.", "Она начала новую работу в мае."],
    ["The first week was difficult.", "Первая неделя была трудной."]
  ] }
```

Каждое предложение — пара «английский, русский». Все слова текста должны быть
в словаре `gloss` в том же файле (ключ — словоформа в нижнем регистре):

```js
gloss: { "started": "начала (start)", "difficult": "трудный" }
```

Начальная форма ставится в скобки — из неё собирается карточка по кнопке
«＋ в словарь». Если слова не будет в `gloss`, при наведении появится честная
пометка «перевода нет» — текст из-за этого не сломается.

**Тексты в этом файле написаны специально для тренажёра.** Не копируй сюда
чужие тексты с сайтов и из учебников: они защищены авторским правом.

## Проверка ответов при вводе

Засчитывается, если:

* регистр любой — `access` = `Access`;
* артикль и частица `to` написаны или нет — `the access` = `to access` = `access`;
* знаки препинания в конце не мешают;
* для пар вида `labor | labour` достаточно любой из форм.

**Буквы проверяются точно.** Приложение не «догадывается» за тебя:

| Ответ | Написано | Результат |
|---|---|---|
| `achieve` | `Achieve.` | засчитано |
| `achieve` | `to achieve` | засчитано |
| `achieve` | `acheive` | «почти верно», просит переписать |
| `achieve` | `acquire` | не засчитано |
| `analyze` | `analyse` | засчитано — британский вариант стоит в `accept` |
| `labor` | `labour` | засчитано — там же |

Ошибка ровно в одну букву — это «почти верно»: ответ не засчитывается как
неправильный, можно сразу переписать. Второе допустимое написание слова
(британское или американское) задаётся полем `accept` — само приложение такие
пары не придумывает.

## Озвучка

Работает встроенным голосом системы, офлайн; приложение выбирает американский
голос, если он есть. Если кнопка 🔊 молчит, английский голос не установлен:
**Системные настройки → Универсальный доступ → Устный контент → Системный голос →
Управление голосами → английский**. Скорость речи настраивается в ⚙ Настройках.

## Прогресс

Хранится в самом браузере (localStorage), на этом компьютере. По каждому слову
запоминается ступень, число правильных и неправильных ответов и звёздочка —
отдельно для каждого модуля. Сбросить можно как один модуль, так и всё сразу:
⚙ Настройки. В другом браузере или в режиме инкогнито прогресс будет свой.

## Как добавить слова

### Через приложение

Главный экран → **＋ Добавить слова**.

1. Выбрать модуль (или **«＋ Новый модуль»** и задать название).
2. При необходимости выбрать **часть речи** — по умолчанию она определяется
   сама по концовке слова: `-tion/-ment/-ity` — существительное, `-ous/-ful/-ive` —
   прилагательное, `-ize/-ify/-ate` или `to ...` — глагол, `-ly` — наречие.
   Угадывание английской части речи — вещь приблизительная, так что для глагола
   лучше выбрать её руками: от этого зависит, попадёт ли слово в «Формы глагола».
3. Вставить строки в формате:

```
перевод = word | транскри́пция | мн. ч. | транскри́пция мн. ч.
гипотеза = hypothesis | хайпо́сэсис | hypotheses | хайпо́сэсиз
источник = source | сорс
```

4. Нажать **«Добавить»** — всё. Слова сразу доступны во всех тренировках,
   ничего копировать и вставлять в файл не нужно.

**Глаголы попадают и в «Формы глагола»** — сразу со всеми формами и правилами.
Примера в словаре у дописанного глагола нет, поэтому задание выглядит коротко
(«He has sought.»), а во вкладке с переводом — как «Он (искать).». Чтобы
задания были полноценными, допиши глаголу `ex`, `exRu` и `exRuPast` в `words.js`.

Ошиблась в написании — слово можно убрать: **Список слов** → найти его →
крестик ✕ справа. Крестик есть только у слов, добавленных в приложении;
слова из `words.js` так не удаляются.

Ударение ставится кнопкой «Ударение» или `Alt+A`.

Добавленное в приложении хранится **в браузере**, а не в `words.js`. Для модулей
из файла это видно в ⚙ Настройках пометкой «+N в браузере», там же кнопки
**«Выгрузить дописанные»** (даёт готовые строки для `words.js`, если хочется
сохранить их насовсем) и **«Убрать дописанные»**.

### Прямо в `words.js`

Новый модуль — это ещё один блок в списке:

```js
window.WORD_SETS = [
  { id: "toefl-easy", name: "TOEFL · Лёгкие слова", words: [ /* ... */ ] },

  { id: "unit-3", name: "Юнит 3", words: [
      { en: "source", tr: "сорс", ru: "источник", pos: "сущ.",
        def: "the place where something comes from",
        ex: "Name the source of the data.", exRu: "Назови источник данных." },
      { en: "seek", tr: "сик", ru: "искать, добиваться", pos: "глаг.",
        forms: "sought, sought",
        ex: "He seeks a new job.", exRu: "Он ищет новую работу.",
        exRuPast: "Он искал новую работу." }
  ] }
];
```

`id` должен быть уникальным и его **нельзя менять потом** — к нему привязан
прогресс модуля. `name` можно переименовывать свободно.

Поля слова:

| Поле | Обязательное | Что это |
|---|---|---|
| `en` | да | английское слово |
| `tr` | да | русская транскрипция с ударением |
| `ru` | да | перевод |
| `pos` | да | `сущ.` `глаг.` `прил.` `нареч.` `мест.` `предл.` `союз` `част.` `числ.` `фраза` |
| `def` | нет | короткое определение по-английски |
| `ex` / `exRu` | нет | пример и его перевод; у глагола — Present Simple, 3-е лицо |
| `exRuPast` | нет | тот же пример по-русски в прошедшем времени |
| `pl` / `plTr` | нет | неправильное множественное число и его транскрипция |
| `forms` | нет | вторая и третья формы неправильного глагола: `"sought, sought"` |
| `noIng` | нет | у глагола-состояния формы на `-ing` не бывает |
| `conj` | нет | перекрыть посчитанную форму: `{ past: "spent" }` |
| `note` | нет | уточнение мелким шрифтом |
| `accept` | нет | доп. написания, которые засчитываются при вводе |

Слово опознаётся по паре `en` + `ru` внутри своего модуля — id у слов не нужен.

### Из нового PDF со словами

```bash
python3 tools/pdf_to_words.py words.pdf                   > новый_модуль.txt
python3 tools/pdf_to_words.py words.pdf "TOEFL · Глаголы" > новый_модуль.txt
```

Скрипт печатает **готовый модуль целиком** — с `id`, названием и словами.
Блок нужно вставить в `words.js` перед самой последней скобкой `]`.

Он понимает и строки вида «word — перевод», и таблицы, где слово и перевод
стоят в разных колонках, и подставляет **черновую** транскрипцию с пометкой
`tr_draft: true`. Черновик нужно просмотреть глазами: английское чтение
по написанию угадывается плохо, а ударение всегда ставится на первый гласный.

## Правила транскрипции

Чтобы новые слова выглядели так же, как уже записанные:

| Английское | Русское | Пример |
|---|---|---|
| `æ` (`a` в закрытом слоге) | э | `access` → э́ксес |
| `ʌ` (`u`) | а | `study` → ста́ди |
| `ɜː` (`ir`, `ur`, `er` под ударением) | ё | `research` → рисё́рч |
| `ə` (безударный) | э | `about` → эба́ут |
| `iː`, `ee`, `ea` | и | `achieve` → эчи́в |
| `uː`, `oo` | у | `assume` → эсу́м |
| `eɪ`, `ai`, `ay` | эй | `maintain` → мэйнте́йн |
| `aɪ`, `igh` | ай | `identify` → айде́нтифай |
| `oʊ`, `oa` | оу | `focus` → фо́укэс |
| `aʊ`, `ou` | ау | `account` → эка́унт |
| `θ` (`th` глухое) | с | `theory` → си́эри |
| `ð` (`th` звонкое) | з | `there` → зэр |
| `w` | у | `welfare` → уэ́лфэр |
| `ŋ`, `ng` | нг | `strong` → стронг |
| `ʃ`, `sh`, `-tion` | ш, -шн | `tradition` → трэди́шн |
| `tʃ`, `ch`, `-ture` | ч, -чэр | `culture` → ка́лчэр |
| `dʒ`, `j`, `g` перед `e, i` | дж | `region` → ри́джэн |

Ударение ставится знаком `◌́` сразу после гласной. У односложных слов и там,
где ударная `ё`, знак не нужен: `сорс`, `кор`.

## Словарь в PDF

В папке лежит **`Словарь.pdf`** — все слова таблицей «слово · произношение ·
перевод», с определением по-английски под переводом, разбитые по модулям,
с оглавлением на первой странице. Удобно распечатать или открыть с телефона.

Пересобрать после пополнения словаря — две команды:

```bash
node tools/make_pdf.js
```

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --disable-gpu --no-pdf-header-footer --print-to-pdf="Словарь.pdf" "tools/dictionary.html"
```

Первая собирает `tools/dictionary.html` из `words.js`, вторая печатает его
в PDF. Промежуточный HTML в репозиторий не попадает.
