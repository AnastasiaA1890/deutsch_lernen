# Немецкие слова — локальный тренажёр

Аналог Quizlet, который работает прямо с этой папки: без интернета, без сервера,
без установки. Слова показываются с русской транскрипцией и ударением:
**Haus (ха́ус)**, **Straße (штра́сэ)**.

Каждая партия слов — **отдельный модуль** со своим собственным прогрессом,
который тренируется независимо от остальных.

## Как запустить

Дважды кликнуть по **`index.html`** — откроется в браузере. Всё.

Совет: перетащи вкладку в закладки, чтобы открывать в один клик.

## Модули

Каждая загруженная партия слов живёт отдельным модулем: «Набор 1 · LEO»,
«Глаголы, урок 3» и так далее. Модуль выбирается плиткой на главном экране,
и дальше **всё** — карточки, тест, заучивание, пары, список слов — работает
только с его словами.

У каждого модуля свои:

* прогресс по каждому слову (новое / учу / выучено) и общий процент;
* незаконченный раунд заучивания — он ждёт возвращения именно в этом модуле;
* рекорд в «Подборе пар»;
* сброс прогресса (⚙ Настройки → нужный модуль → «Сбросить»).

Одно и то же слово в разных модулях учится независимо: выучил `Haus` в одном —
в другом оно останется новым.

Плитка **«Все модули»** (появляется, когда модулей больше одного) тренирует всё
сразу; прогресс при этом по-прежнему считается для каждого модуля свой.

## Режимы

| Режим | Что делает |
|---|---|
| **Заучивание** | Главный режим. Раунды по 7 слов, каждое слово проходит три ступени: выбор перевода → выбор немецкого слова → написать самому. Ошибся — слово падает на ступень назад и возвращается в этот же раунд. Незаконченный раунд восстанавливается после закрытия браузера. |
| **Карточки** | Классические карточки: клик или пробел — перевернуть, «знаю / не знаю». Отметки и место в колоде сохраняются. Переключается, что показывать спереди — немецкое или русское. |
| **Тест** | Выбор из четырёх вариантов в обе стороны, 10/20/50/все слова. В конце — список ошибок и кнопка «повторить ошибки». |
| **Ввод с клавиатуры** | Написать немецкое слово по русскому переводу. |
| **Подбор пар** | Собрать 6 пар на скорость, с таймером и рекордом. |
| **Спряжение** | Окончания глаголов в Präsens по всем лицам. Появляется, если в модуле есть глаголы. |
| **Список слов** | Все слова, поиск (по немецкому, переводу и транскрипции), озвучка, отметка ⭐ «сложное». |
| **Чтение** | 30 коротких текстов A1 с переводом слов и предложений по наведению. **Не зависит от модулей со словами.** |

После каждого ответа — верного или неверного — открывается разбор: слово,
транскрипция, перевод, множественное число и ступень заучивания. Разбор
**не исчезает сам**, следующий вопрос появляется по кнопке «Дальше» или `Enter`.

Полоса наверху показывает движение по текущему раунду (`3 / 7`) — она сдвигается
после каждого верного ответа. Общий счётчик «выучено N из M» растёт медленнее:
слово попадает в выученные, только пройдя все три ступени.

Наверху главного экрана выбирается модуль, а под ним — **что тренировать**:
все слова, только новые, невыученные, сложные (те, где были ошибки) или
отмеченные звёздочкой.

### Горячие клавиши

| Клавиша | Действие |
|---|---|
| `1`–`4` | выбрать вариант ответа |
| `Enter` | проверить ответ / следующий вопрос |
| `Пробел` | перевернуть карточку |
| `←` `→` | предыдущая / следующая карточка |
| `↑` `↓` | на карточке: «знаю» / «не знаю» |
| `S` | озвучить слово на карточке |
| `Esc` | вернуться на главный экран |

## Карточки

Отметки **«знаю / не знаю» сохраняются** — отдельно для каждого модуля.
Вернувшись, видишь то же, что оставила: колода в том же порядке, карточка
та же, на которой остановилась, точки внизу — зелёные у известных слов
и красные у незнакомых. Под точками стоит счёт «знаю · не знаю · без отметки»
и ссылка **«очистить отметки»**, если хочется начать разбор заново.

«Перемешать» и «Пройти заново» меняют порядок, но отметки не трогают.
Сброс прогресса модуля в ⚙ Настройках очищает и их тоже.

## Спряжение глаголов

Отдельный режим для **всех глаголов** текущего модуля, с двумя вкладками.

### Вкладка «Окончания»

На каждый глагол — пять строк, в которые нужно вписать форму настоящего времени:

| Строка | Перевод | Почему так |
|---|---|---|
| `Ich` | я | |
| `Du` | ты | |
| `Er/sie/es` | он, она, оно | у всех трёх форма одинаковая |
| `Wir/sie/Sie` | мы, они, Вы | совпадает с инфинитивом у всех трёх |
| `Ihr` | вы | |

* Под каждой строкой — **перевод именно этой формы**: «я бегаю», «ты бегаешь».
* Рядом — сворачиваемая подсказка **«? правило»**: какое правило работает
  в этой строке. Например, для `du` от `arbeiten` — что основа оканчивается
  на `-t`, поэтому вставляется соединительное `-e-`; а для `ihr` от `laufen` —
  что чередование `au → äu` здесь, в отличие от `du` и `er`, не происходит.
  Открытые подсказки не закрываются при проверке.
* Наверху — счётчик верных ответов и кнопки **«Проверить всё»**,
  **«Показать ответы»**, **«Сбросить»**.
* Строка проверяется сама, как только уйдёшь из поля, или по `Enter` —
  `Enter` заодно перескакивает к следующей строке.
* Верно — **зелёная** рамка и ✓. Неверно — **красная** рамка и правильная форма
  рядом; если ошибка только в умляуте (`wachst` вместо `wächst`), к ней
  добавляется пометка «умляут».
* Если у глагола меняется основа, в шапке стоит жёлтая пометка вида
  **основа: a → ä**, чтобы было понятно, где подвох.
* **Ответы сохраняются.** Закрыл вкладку, выключил компьютер, вернулся через
  неделю — видно, что уже отработано: верные строки остаются зелёными вместе
  с тем, что ты написала, ошибки — красными и открытыми для правки. В шапке
  каждого глагола стоит счётчик вида **3 / 5**, а когда сделано всё — он
  становится зелёным. Отдельно для каждой вкладки и каждого модуля.
* «Сбросить» очищает только текущую вкладку; сброс прогресса модуля
  в ⚙ Настройках очищает и упражнения по спряжению тоже.

### Вкладка «Перевод предложений»

Те же самые предложения, но целиком и с русского на немецкий:

| Задание | Ответ |
|---|---|
| Я учу немецкий | `Ich lerne Deutsch.` |
| Ты быстро бегаешь | `Du läufst schnell.` |
| Он живёт в Берлине | `Er wohnt in Berlin.` |

* Регистр и точка в конце не важны: `ich lerne deutsch` засчитывается.
  А вот умляуты и `ß` — важны, как и везде в тренажёре.
* Для третьего лица засчитываются все варианты местоимения: `Er lernt…`,
  `Sie lernt…`, `Es lernt…`; для `wir` — ещё и `Sie lernen…`.
* У каждой строки есть сворачиваемая **«? подсказка»**: правильное предложение
  целиком, кнопка **🔊 послушать** и то же правило, что во вкладке «Окончания» —
  какое окончание и почему. Открытая подсказка не закрывается при проверке.
* Счётчик, «Проверить всё», «Показать ответы» и «Сбросить» работают отдельно
  для каждой вкладки, а ответы при переключении не пропадают и переживают
  перезагрузку страницы.

Формы считаются по правилам немецкого языка, включая соединительную `-e`
(`du arbeitest`, но `du wohnst`), глаголы на `-s/-ß/-z` (`du heißt`),
на `-eln/-ern` (`ich sammle`, `du wanderst`) и чередование гласной в основе
у `du` и `er` (`fahren → du fährst`, `sehen → du siehst`, `laufen → du läufst`).
Полностью неправильные глаголы — `sein`, `haben`, `werden`, `wissen`,
модальные — заданы таблицей целиком.

Чтобы глагол попал в этот режим, у него должно быть `pos: "глаг."`.
Необязательные поля:

```js
{ de: "fahren", tr: "фа́рэн", ru: "ездить, ехать", pos: "глаг.",
  forms: "fuhr, gefahren",
  ex: "nach Berlin",                       // дополнение для предложения
  exRu: "в Берлин",                        // его перевод — для вкладки «Перевод»
  exPre: false,                            // true, если по-русски дополнение
                                           // стоит перед глаголом: «я быстро бегаю»
  ruConj: ["я еду", "ты едешь", "он едет",
           "мы едем", "вы едете", "они едут"],
  conj: { du: "fährst", er: "fährt" } }    // если форма нестандартная
```

`ex` подставляется в предложение: «Ich fahre **nach Berlin**.» — без него
получится просто «Ich fahre.». `exRu` — перевод этого дополнения, из него
собирается русское задание: «Я еду **в Берлин**». Если по-русски дополнение
естественнее стоит перед глаголом («я **быстро** бегаю»), поставь
`exPre: true`.

`ruConj` — перевод всех шести форм по порядку `ich, du, er, wir, ihr, sie`.
Шесть, а не пять: приложение само собирает из них подписи объединённых строк
(`wir` + `sie` → «мы едем · они едут»). Если `ruConj` не указать, под строкой
будет запасная подсказка вида «ты — ездить».

`conj` нужен, только если глагола нет во встроенной таблице неправильных:
он перекрывает любые вычисленные формы.

## Фразы на каждый день

Модуль **«1000 · Фразы на каждый день»** — 163 готовых предложения, собранных
из новых слов и разложенных по ситуациям: приветствие, как дела, время и планы,
кафе, покупки, одежда, врач, дом, работа и учёба, семья, свободное время.
Ситуация подписана под каждой фразой (поле `note`), так что в списке слов
видно, где фраза пригодится.

Фразы учатся как обычные карточки: во «Вводе с клавиатуры» нужно написать
предложение целиком, в «Тесте» — выбрать перевод.

## Чтение

Отдельный раздел с короткими текстами. Он **никак не связан с модулями слов**:
свои тексты, свой словарь подсказок, своя отметка «прочитано». Сейчас там
30 текстов уровня **A1** на 15 тем — день, семья, еда, город, погода, работа,
путешествия, праздники и другие.

Как читать:

* **Наведи на слово** — всплывает перевод. Для глаголов в скобках стоит
  инфинитив (`heiße — меня зовут (heißen)`), для существительных — артикль
  (`Kaffee — кофе (der Kaffee)`).
* **Нажми на слово** — оно произносится вслух.
* **Наведи на точку в конце предложения** (она подсвечена) — перевод всего
  предложения и кнопка **🔊 послушать**. Нажатие на саму точку тоже читает
  предложение целиком.
* **Повторное нажатие останавливает чтение** — и для слова, и для предложения,
  и для всего текста. Кнопка «Слушать текст» при этом превращается
  в «⏹ Остановить».
* В подсказке к слову есть кнопка **«＋ в словарь»** — она складывает слово
  в модуль для изучения (см. ниже).
* Кнопка **«Слушать текст»** читает весь текст, **«Отметить прочитанным»** —
  ставит галочку в списке. Стрелки внизу листают тексты подряд.

### Слово из текста — в модуль

Нажми **«＋ в словарь»** в подсказке. Откроется окно с уже заполненной
заготовкой карточки:

* **немецкое слово** — приложение подставляет начальную форму, а не ту, что
  в тексте: `trinke` → `trinken`, `Kaffee` из «кофе (der Kaffee)» — без артикля;
* **транскрипция** — считается автоматически по тем же правилам, что в
  конвертере PDF. Это черновик: ударение ставится по общему правилу, так что
  его стоит проверить. Под полем есть кнопки гласных с ударением;
* **перевод** и **часть речи** — тоже заготовка, всё можно поправить;
* **модуль** — существующий «свой» модуль или новый (по умолчанию
  «Слова из текстов»).

Такой модуль **хранится в браузере**, а не в `words.js`, и сразу доступен во
всех тренировках со своим отдельным прогрессом. На главном экране и в
настройках он помечен значком «в браузере».

Чтобы сохранить его насовсем: ⚙ Настройки → нужный модуль → **«Выгрузить в
words.js»** → скопировать блок и вставить в файл. `id` при этом сохраняется,
поэтому прогресс не потеряется, а модуль из браузера можно будет удалить.

Пополнять «свой» модуль можно и через экран **«＋ Добавить слова»** — если
выбрать его как цель, слова добавятся сразу, без возни с кодом.

Тексты фильтруются по уровню и по теме. Уровень пока один — A1, но структура
рассчитана на A2 и дальше: достаточно дописать тексты с другим `level`.

### Как добавить свой текст

Тексты лежат в `texts.js` отдельно от слов:

```js
{ id: "t31", level: "A2", topic: "Работа",
  title: "Mein Job", titleRu: "Моя работа",
  s: [
    ["Ich arbeite in einem Büro.", "Я работаю в офисе."],
    ["Die Arbeit macht mir Spaß.", "Работа мне нравится."]
  ] }
```

Каждое предложение — пара «немецкий, русский». Все слова текста должны быть
в словаре `gloss` в том же файле (ключ — словоформа в нижнем регистре):

```js
gloss: { "spaß": "удовольствие (der Spaß)", "macht": "делает (machen)" }
```

Если слова не будет в `gloss`, при наведении появится честная пометка
«перевода нет» — текст из-за этого не сломается.

**Тексты в этом файле написаны специально для тренажёра.** Не копируй сюда
чужие тексты с сайтов и из учебников: они защищены авторским правом.

## Проверка ответов при вводе

Засчитывается, если:

* регистр любой — `haus` = `Haus`;
* артикль написан или нет — `das Haus` = `Haus`;
* для пар вида `Freund | Freundin` достаточно любой из форм.

**Артикль писать не обязательно, но если написан — должен быть верным.**
`Bus` и `der Bus` засчитываются одинаково, а `die Bus` — нет: приложение
скажет, какой артикль нужен, и попросит переписать. Это работает для слов,
у которых артикль записан в словаре (модуль «Набор 2 · с артиклями»).

**Умляуты и `ß` проверяются строго.** Ни `o` вместо `ö`, ни `oe` вместо `ö`
не засчитываются — и наоборот, `ö` вместо `o` тоже ошибка:

| Ответ | Написано | Результат |
|---|---|---|
| `Tür` | `Tür` | засчитано |
| `Tür` | `Tur` · `Tuer` | не засчитано, просит переписать |
| `Straße` | `Strasse` | не засчитано |
| `groß` | `gross` | не засчитано |
| `Haus` | `Häus` | не засчитано |
| `der Bus` | `Bus` | засчитано |
| `der Bus` | `die Bus` | не засчитано, неверный артикль |

В таком случае приложение прямо говорит, какие особые буквы есть в слове
(«в этом слове есть **ü**»), но само слово не показывает — его нужно написать
правильно. Под полем ввода стоят кнопки `ä ö ü ß Ä Ö Ü`: если на клавиатуре
умляутов нет, символ вставляется одним нажатием.

Ошибка ровно в одну обычную букву — это «почти верно»: ответ не засчитывается
как неправильный, можно сразу переписать.

## Озвучка

Работает встроенным голосом системы, офлайн. Если кнопка 🔊 молчит,
немецкий голос не установлен:
**Системные настройки → Универсальный доступ → Устный контент → Системный голос →
Управление голосами → немецкий**. Скорость речи настраивается в ⚙ Настройках.

## Прогресс

Хранится в самом браузере (localStorage), на этом компьютере. По каждому слову
запоминается ступень, число правильных и неправильных ответов и звёздочка —
отдельно для каждого модуля. Сбросить можно как один модуль, так и всё сразу:
⚙ Настройки. В другом браузере или в режиме инкогнито прогресс будет свой.

## Как добавить слова

### Через приложение

Главный экран → **＋ Добавить слова**.

1. Выбрать модуль (или **«＋ Новый модуль»** и задать название).
2. При необходимости выбрать **часть речи** — по умолчанию она определяется
   сама: слово на `-en/-ern/-eln` считается глаголом, с большой буквы или
   с артиклем — существительным, с точкой или пробелом — фразой.
3. Вставить строки в формате:

```
перевод = Wort | транскри́пция | Мн.ч. | транскри́пция мн.ч.
дом = Haus | ха́ус | Häuser | хо́йзэр
окно = Fenster | фэ́нстэр
```

4. Нажать **«Добавить»** — всё. Слова сразу доступны во всех тренировках,
   ничего копировать и вставлять в файл не нужно.

**Глаголы попадают и в «Спряжение»** — сразу со всеми формами и правилами.
Если слово было добавлено раньше и попало туда с пометкой «сущ.», приложение
чинит это само при запуске: строчное слово на `-en/-ern/-eln` — это глагол.

Ошиблась в написании — слово можно убрать: **Список слов** → найти его →
крестик ✕ справа. Крестик есть только у слов, добавленных в приложении;
слова из `words.js` так не удаляются.
Русских форм (`ruConj`) у дописанного глагола нет, поэтому во вкладке
«Перевод предложений» задание выглядит как «Я (танцевать)» → `Ich tanze.`
Чтобы задания были полноценными («Я танцую быстро»), допиши глаголу
`ruConj`, `ex` и `exRu` в `words.js`.

Ударение ставится кнопкой «Ударение» или `Alt+A`.

Добавленное в приложении хранится **в браузере**, а не в `words.js`. Для модулей
из файла это видно в ⚙ Настройках пометкой «+N в браузере», там же кнопки
**«Выгрузить дописанные»** (даёт готовые строки для `words.js`, если хочется
сохранить их насовсем) и **«Убрать дописанные»**.

### Прямо в `words.js`

Новый модуль — это ещё один блок в списке:

```js
window.WORD_SETS = [
  { id: "leo-1", name: "Набор 1 · LEO", words: [ /* ... */ ] },

  { id: "urok-3", name: "Глаголы, урок 3", words: [
      { de: "lesen", tr: "ле́зэн", ru: "читать", pos: "глаг.", forms: "las, gelesen" },
      { de: "Fenster", tr: "фэ́нстэр", ru: "окно", pos: "сущ.", pl: "Fenster", plTr: "фэ́нстэр" }
  ] }
];
```

`id` должен быть уникальным и его **нельзя менять потом** — к нему привязан
прогресс модуля. `name` можно переименовывать свободно.

Поля слова:

| Поле | Обязательное | Что это |
|---|---|---|
| `de` | да | немецкое слово; артикль можно включить (`der Bus`) — тогда он проверяется |
| `tr` | да | русская транскрипция с ударением |
| `ru` | да | перевод |
| `pos` | да | `сущ.` `глаг.` `прил.` `нареч.` `мест.` `предл.` `част.` `числ.` `фраза` |
| `pl` / `plTr` | нет | множественное число и его транскрипция |
| `forms` | нет | формы сильного глагола: `"lief, gelaufen"` |
| `note` | нет | уточнение мелким шрифтом |
| `accept` | нет | доп. варианты, которые засчитываются при вводе |

Слово опознаётся по паре `de` + `ru` внутри своего модуля — id у слов не нужен.

### Из нового PDF со словами LEO

```bash
python3 tools/pdf_to_words.py 2.pdf                    > новый_модуль.txt
python3 tools/pdf_to_words.py 2.pdf "Глаголы, урок 3"  > новый_модуль.txt
```

Скрипт печатает **готовый модуль целиком** — с `id`, названием и словами.
Блок нужно вставить в `words.js` перед самой последней скобкой `]`.

Артикли он срезает сам, достаёт множественное число и формы глаголов и
подставляет **черновую** транскрипцию с пометкой `tr_draft: true`. Черновик
совпадает с ручной транскрипцией примерно в 7 случаях из 10 — ударение и
шипящие обязательно просмотреть глазами, а пометку убрать.

## Правила транскрипции

Чтобы новые слова выглядели так же, как уже записанные:

| Немецкое | Русское | Пример |
|---|---|---|
| `ei`, `ai` | ай | `heiß` → хайс |
| `ie` | и | `spielen` → шпи́лэн |
| `eu`, `äu` | ой | `Häuser` → хо́йзэр |
| `au` | ау | `Haus` → ха́ус |
| `ä` | э (кратко), е (долго) | `Städte` → ште́тэ, `Käse` → ке́зэ |
| `ö` | ё | `schön` → шён |
| `ü` | ю | `Tür` → тюр |
| `sch` | ш | `Tisch` → тиш |
| `st-`, `sp-` в начале | шт-, шп- | `Stadt` → штат |
| `s` перед гласной | з | `Sonne` → зо́нэ |
| `ß`, `ss` | с | `Straße` → штра́сэ |
| `z`, `tz` | ц | `Katze` → ка́цэ |
| `v` | ф | `Vater` → фа́тэр |
| `w` | в | `Wasser` → ва́сэр |
| `j` | й (`ja` → я) | `jung` → юнг |
| `ch` после `a, o, u` | х | `Nacht` → нахт |
| `ch` в остальных случаях | хь / хе | `Licht` → лихьт, `Bücher` → бю́хер |
| `-er` в конце | -эр | `Bruder` → бру́дэр |
| `-e`, `-en` в конце | -э, -эн | `Lampe` → ла́мпэ, `Lampen` → ла́мпэн |
| `b`, `d`, `g` в конце | п, т, к | `Tag` → так, `Abend` → а́бэнт |

Ударение ставится знаком `◌́` сразу после гласной. У односложных слов и там,
где ударная `ё`, знак не нужен: `хайс`, `шён`.
